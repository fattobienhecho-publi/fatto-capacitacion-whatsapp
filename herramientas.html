Producto 01

Stickers personalizados

Editable

Link de apoyo / GPT de diseño

Pega aquí el link del GPT o herramienta para stickers.

Prompt para iniciar conversación

Crea una respuesta de WhatsApp para un cliente interesado en stickers personalizados. Debe responder directo, preguntar para qué los necesita y pedir solo logo o referencia para avanzar.

Prompt para finalizar / cerrar

Crea una respuesta corta para cerrar la venta de stickers cuando el diseño ya está aprobado. Debe confirmar impresión, recordar el valor y pasar a opciones de envío y pago.

Precios base

Aplican para stickers circulares, cuadrados y con corte según forma.

  • Stickers de 3 cm: 55.000.
  • Stickers de más de 4 cm: 35.000.

Circulares o cuadrados

  • Máximo 2 diseños por pliego.
  • Diseño adicional: 10.000.

Corte según forma

  • Solo se permite 1 diseño por pliego.
  • Después de 5 pliegos, se descuenta 5.000 al valor liquidado inicialmente.

Laminado tornasol

  • Mínimo 2 pliegos.
  • Valor: 50.000 por pliego.

Tiempos

  • Producción: 2 días después de aprobado el diseño.
  • Envío: 3 a 5 días hábiles después de producción.

Nota importante

El color puede variar entre pantalla e impresión. En pantalla se ve en RGB y en impresión se maneja CMYK.

Producto 02

Camisetas personalizadas

Editable

Link del GPT de diseño

Pega aquí el link del GPT que diseña las camisetas.

Prompt para iniciar conversación

Crea una respuesta de WhatsApp para un cliente interesado en camisetas personalizadas. Debe responder directo, explicar que se trabaja un diseño profesional y pedir logo, referencia, tallas y color de camiseta.

Prompt para finalizar / cerrar

Crea una respuesta corta para cerrar una venta de camisetas personalizadas cuando el cliente ya aprobó el diseño. Debe confirmar producción, validar tallas y pasar a opciones de envío y pago.

Qué incluye

  • Incluye 1 solo diseño.
  • Pueden ir dos colores de camiseta con el mismo diseño.
  • Incluye tallas XS, S, M, L y XL.

Costos adicionales

  • Segundo diseño: 20.000 adicionales por diseño.
  • Talla XXL: 10.000 adicionales por camiseta.

Nota importante

Tener en cuenta la gama de colores propuesta para la campaña.
