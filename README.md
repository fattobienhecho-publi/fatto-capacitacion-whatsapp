# Ventas por WhatsApp - FATTO Bien Hecho

Pagina web estatica para capacitacion comercial de ventas por WhatsApp.

## Publicacion en GitHub Pages

1. Crear un repositorio nuevo en GitHub.
2. Subir todos los archivos de esta carpeta al repositorio.
3. Ir a `Settings > Pages`.
4. En `Build and deployment`, seleccionar:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. Guardar y esperar a que GitHub genere el enlace publico.

El sitio usa `index.html`, `styles.css`, `script.js` y la carpeta `assets`.
